# Media Assets

Photographs, schematics, web interface captures, and video demonstrations of the ESP8266 Servo-Based Hand Assistance prototype:

- **`prototype.jpg`**: Primary hardware prototype setup featuring the ESP8266 NodeMCU V3, custom perfboard power bus, and SG90 mini servo actuators.
- **`prototype_view2.jpg`**: Alternate angle photograph of the prototype breadboard/perfboard assembly and cabling.
- **`web_dashboard.png`**: Smartphone screenshot of the embedded Web Control Dashboard accessed over the ESP8266 local Wi-Fi Hotspot (`192.168.4.1`).
- **`demonstration.mp4`**: Video demonstration showing servo sweep and hold cycles (to be added).
